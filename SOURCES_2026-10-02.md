# GratisCash · fuentes del catálogo editorial inicial verificadas el 02/10/2026

Este archivo documenta las fuentes utilizadas para preparar el catálogo inicial de GratisCash. No constituye una garantía de que las campañas continúen activas: deben revalidarse antes de publicación y periódicamente mientras estén visibles como activas.

Las oportunidades iniciales se basan en páginas oficiales o páginas de campaña de sus respectivos proveedores, entre ellas trnd, Ipsos iSay, Toluna, MOBROG, Gelt, Revolut y Roamler.

## Reglas editoriales
- Guardar siempre la fuente oficial.
- No inventar recompensa, disponibilidad, plazas, votos ni comentarios.
- Registrar fecha de última comprobación.
- Archivar cuando finaliza o deja de estar disponible.
- Si la misma URL se reutiliza para una campaña distinta, moderación debe comprobar título, fechas y condiciones antes de tratarla como duplicado.
- Separar siempre fuente oficial de enlace afiliado.

## Imágenes
Antes de producción, cada imagen debe ser propia o contar con autorización/licencia compatible con el uso previsto. Guardar `photo_credit` y `photo_source_url` cuando aplique. Las imágenes de una marca no deben presentarse como oficiales si no lo son.

## Revalidación
No lanzar automáticamente campañas antiguas por el mero hecho de existir en este seed. La administración debe comprobarlas manualmente justo antes de hacer pública la base de producción.
